# 作業彙總

此檔案提供快速彙整，方便檢視各子資料夾重點：

- 01/: 個人簡介範例（aboutme.html）— HTML 基本排版與圖片、文字介紹。
- 02/: 表單練習（form.html）— 表單元素、驗證、提交範例。
- 03/: 多個 JS 練習檔（01.js ~ 10.js）— 基礎語法、DOM 操作、事件處理。
- 04/ & 05/: blog/ 相關— 部落格範例結構與靜態頁面。
- 07/ & 08/: 類似 03 的 JS 練習集，個別檔案為不同題目。
- js/: 共用腳本與教學範例（hello.js）。
- mid exam/: 期中考練習，包含 `server.js`（Node 範例）與 `package.json`。

如需把某個子資料夾打包、部署或轉成可展示的範例頁，告訴我你要的目標（例如 GitHub Pages 或本地 server），我會幫你準備步驟。
