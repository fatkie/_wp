# myhomework

此資料夾為課堂作業彙整，包含各週或各題目的練習檔案與範例。

目錄概覽：

- `01/` — 個人簡介範例（aboutme.html）
- `02/` — 表單範例（form.html）
- `03/` — 多個練習的 JavaScript 檔案
- `04/`, `05/` — 部落格相關子資料夾
- `07/`, `08/` — 其他練習的 JavaScript 檔案
- `js/` — 共用或教學用的 JavaScript（例如 hello.js）
- `mid exam/` — 期中考相關檔案（包含 server.js 與 package.json）

如何使用：

1. 瀏覽各子資料夾了解每題內容。
2. 若要執行有 Node.js 的範例（例如 `mid exam/`），先在該子資料夾執行 `npm install`，再用 `node server.js` 啟動（若有提供）。
3. 若需要我幫忙整理或將某個練習獨立成示範檔，請告訴我要處理的子資料夾名稱。

聯絡：若想要我補上更詳盡的說明或範例，回覆想要的內容即可。
