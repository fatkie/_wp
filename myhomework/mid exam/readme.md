# 🎵 節奏遊戲 - 雲端排行榜網頁版 (Web Rhythm Game)

這是一款使用純 HTML、CSS、JavaScript 打造的 **4 鍵式網頁節奏遊戲**。玩家可以直接在瀏覽器中遊玩，無需安裝任何主程式！
本遊戲支援讀取 `osu!` 的 `.osz` 譜面檔，並結合 **Firebase** 提供帳號註冊、登入以及「雲端全國排行榜」與「本地排行榜」功能。

---

## ✨ 遊戲特色

* **免安裝，隨開即玩**：只要有瀏覽器就能玩，完全靜態網頁架構，可輕易部署至 Netlify 或 GitHub Pages。
* **支援 osu! 譜面**：可直接上傳 `.osz` 或 `.zip` 格式的 osu!mania 4K 譜面檔，遊戲會自動解析歌曲與難度。
* **雙排行榜系統**：
    * **本地排名**：將成績保存在瀏覽器緩存 (localStorage) 中，即使不登入、沒網路也能記錄自己的最佳成績。
    * **全國排名**：登入帳號後，過關成績會自動上傳至 Firebase 即時資料庫，與其他玩家爭奪神人寶座！
* **進階遊戲體驗**：
    * 流暢的 2.5 秒進場緩衝時間 (Lead-in Time)。
    * 遊戲中可按 `ESC` 呼叫暫停選單。
    * 完美 (Perfect)、優秀 (Good)、失誤 (Bad/Miss) 判定系統與連擊 (Combo) 特效。
    * 支援長條音符 (Hold Notes)。

---

## 🎮 如何遊玩

1.  **進入遊戲**：開啟遊戲網頁。
2.  **登入/註冊 (選用)**：
    * 在畫面上方輸入「帳號(名稱)」與「密碼」(至少6碼) 進行註冊或登入。
    * *註：若不登入，依然可以遊玩並記錄本地成績。*
3.  **載入歌曲**：
    * 點擊「選擇檔案」，上傳你準備好的 `.osz` 或 `.zip` 譜面檔。
    * 選擇你想要遊玩的「歌曲」與「難度」。
4.  **設定速度**：可自由調整音符掉落速度。
5.  **開始遊戲**：點擊「開始遊戲」，倒數 3 秒後音符將開始落下！

### ⌨️ 操作按鍵

* **打擊按鍵**：`D`、`F`、`J`、`K`
* **長條音符**：按住對應按鍵，直到長條結束再放開。
* **暫停遊戲**：遊戲進行中按下 `ESC`。

## 🛠️ 開發與部署指南

如果你想要將這款遊戲部署到自己的網址，請按照以下步驟操作：

### 1. Firebase 專案設定

本遊戲依賴 Google Firebase 作為後台資料庫，你需要準備自己的 Firebase 專案：

1.  前往 [Firebase Console](https://console.firebase.google.com/) 建立一個新專案。
2.  **啟用 Authentication (身分驗證)**：
    * 選擇 `Email/Password` (電子郵件/密碼) 登入方式並「啟用」。
3.  **啟用 Realtime Database (即時資料庫)**：
    * 建立資料庫後，前往 **Rules (規則)** 標籤，將讀寫權限開啟：
      ```json
      {
        "rules": {
          ".read": true,
          ".write": true
        }
      }
      ```
4.  **取得設定碼**：
    * 在「專案設定」中，註冊一個網頁應用程式 (Web App)，複製你的 `firebaseConfig` 程式碼。
    * 打開遊戲的 `index.html`，將檔案中的 `firebaseConfig` 替換成你專屬的設定。

### 2. 部署至 Netlify (最推薦)

1.  準備一個資料夾，將 `index.html` 放入其中。
2.  前往 [Netlify Drop](https://app.netlify.com/drop)。
3.  將整個資料夾拖曳到網頁中，Netlify 會自動為你生成一個網址。
4.  **⚠️ 重要**：回到 Firebase 的 Authentication -> Settings -> Authorized domains (已授權網域)，將 Netlify 產生給你的網址加進白名單，否則登入功能會被阻擋！
